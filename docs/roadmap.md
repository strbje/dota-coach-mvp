## Идеи из открытого Dota coach — 30.09.2026

Источник: [atlonis/dota2-coach-skill](https://github.com/atlonis/dota2-coach-skill/tree/88517196041f5644b27aca303aadc81f870ccffe).
Проверены README, runtime queries, baseline, personal progress и протокол проверки на
реальных матчах. Это устанавливаемый skill для ИИ-агентов с CLI и JSON/Markdown-выводом.
В проверенном дереве нет веб-приложения, в metadata нет homepage; публичный сайт не найден.
Это пересекающийся по назначению проект, но не подтверждённый готовый аналог нашего сайта.

Предлагаемый порядок развития (идеи, не реализованные функции этого патча):

| Приоритет | Возможность | Что переиспользовать у нас / что проверить |
|---|---|---|
| 1 | Проверить пользу разбора на реальных матчах | Существующие priorities и факты #59: сравнить с оценкой владельца, найти фактические ошибки и проверить, понятно ли действие. Отдельно проверять матчи без явной проблемы. |
| 2 | Углубить фактический фарм: линия / нейтралы и конкретные периоды | Продолжить #34, нормализаторы экономики и существующие источники. Сначала сверить события добивания и временные отметки; не объявлять уход в лес ошибкой по одному счётчику. |
| 3 | Личный прогресс и проверка предыдущей цели | Сравнивать свои матчи по герою, роли, режиму, версии игры и одинаковой временной точке. Для каждой метрики сохранять число реально наблюдаемых матчей. Это личная история, а не норма героя или доказанный эффект упражнения. Нужен отдельный выбор хранения/идентификации. |
| 4 | Эпизоды с объектами, покупками и смертями | Расширять текущие timeline/phase модели: фиксировать известные события и время. Контекст карты требует валидации #50; отсутствие события не доказывает бездействие игрока. |
| 5 | Актуальные описания способностей и предметов | Развивать существующий локальный слой констант, учитывать версию игры и русские отображаемые имена; современное описание нельзя без оговорки применять к старому матчу. |

Прямые средние по рейтинговым группам остаются исследованием из `STRATZ_RESEARCH.md`.
Не подменять среднее процентилем и не переносить чужую формулу оценки. В source repository
не найден LICENSE; реализация текущего probe написана самостоятельно, сторонний код не
скопирован и skill не установлен. Упомянутый проект отвергает старые патчи; такой запрет
для нашего разбора фактов автоматически не вводится.
