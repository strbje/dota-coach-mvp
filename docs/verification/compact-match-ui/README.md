## Повторение

```sh
npm run build
START_SERVER=1 EVIDENCE_DIR=/tmp/compact-postmatch node scripts/verify-post-match-v2.mjs
START_SERVER=1 EVIDENCE_DIR=/tmp/compact-winrates node scripts/verify-winrates.mjs
```

Нужен Playwright/Chromium в окружении (проект их не устанавливает). Поддержаны `PLAYWRIGHT_MODULE_PATH`, `CHROMIUM_MODULE_PATH`, `CHROMIUM_EXECUTABLE_PATH`, `BASE_URL`, `PORT`. Для среды без доступа Chromium к CDN передать `ASSET_DIR` с исходными файлами `heroes-<key>.png` / `items-<key>.png` из URL в manifest. Без него приложение использует обычную загрузку с CDN и безопасный fallback. `LIVE_MATCH_ID` — отдельный необязательный bounded API probe.
