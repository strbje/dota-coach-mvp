# Удобство для игрока и диагностика типов фарма

Проверено 2026-11-06. Ветка основана на `main` после PR #78 (`0b1441b677cdabe77776a6ea8918a8521755c58f`). Все screenshots ниже получены из production-сборки этой доработки. На каждом есть пометка **синтетических данных**: они проверяют интерфейс, а не доступность данных настоящего матча у провайдера.

## Что изменено

- Общая шапка с явным мобильным меню, клавиатурным управлением и восстановлением фокуса по Escape. Частичный EN-переключатель скрыт; старое предпочтение EN не включает смешанный интерфейс. Тематические фоны и общие ограничения ширины из PR #78 сохранены.
- Выбор игрока через два состава с портретом, именем и KDA. Начальный ID пустой; пример заполняется явно. Возврат из последних матчей восстанавливает состав и выбор игрока, но не обходит серверное подтверждение роли.
- На главной — последние пять открытых разборов и незавершённые цели. Данные остаются только в браузере; очистка списка матчей не удаляет цели. При недоступном хранилище разбор по ID работает.
- Вместо общей оценки «Драки» на первом экране показан урон по героям и положение в выборке. Доход и добивания показаны отдельно. Существующие формулы индексов сохранены в подробностях; сравнение не выдаётся за норму рейтинга/роли.
- В личном плане действие видно сразу, повторные объяснения свёрнуты. Проверенные матчи и достижения цели подписаны отдельно. Автоматическое обновление прогресса происходит **при открытии следующего подходящего разбора**, без фонового поиска игр.
- Столбцы фарма показывают числа по типам на месте при наведении, фокусе или выборе. Выбранный отрезок и рекомендуемый эпизод различимы; переход к событиям — отдельная кнопка. На узком экране график прокручивается, подписи не перекрываются.
- На графике ресурсов доступны точное время/значение ближайшего существующего замера и ползунок для клавиатуры/телефона. Промежуточные значения не вычисляются; пробелы золота и опыта остаются пробелами.
- Подготовка к линии: три поля вместо дублирующихся составов, явно указана поддержка Lifestealer/керри, пример по кнопке. Пики изменились — старый план скрывается; запоздалый ответ не подменяет новый ввод. Для неизвестного матчапа сложность не оценивается. Добавлена проверка входа и формы ответа.
- В винрейте карточки матчей показывают героя, дату и подписанные средние сторон. Подписи 7/30 дней, процент, победы/игры и полнота читаются отдельно на мобильном. Формулы, исключение текущего матча, повторные загрузки и независимая полнота окон сохранены.
- Единое обращение на «ты», умеренные термины «фарм», «саппорт», «вижен», «винрейт», «Крипы на линии», «Эншенты». Источники, методика и ограничения доступны в подробностях.

## Неизвестный тип фарма — отдельный результат

Подробности: [UNKNOWN_FARM.md](UNKNOWN_FARM.md), [машинный протокол](farm-type-diagnosis.json), воспроизводимый [offline-скрипт](../../../scripts/inspect-farm-types.mjs).

В сохранённых реальных ответах матчей **9019592113** и **9003795847** у всех 77 неклассифицированных событий три признака типа равны `false`. По существующей расшифровке реальных реплеев это 59 нейтральных frog-юнитов (включая 3 древних), 8 призванных юнитов, 7 строений, вард, Рошан и Терзатель. Все события уже входят в 583 добивания игрока. Скелеты WK учитываются правильно.

Нормализатор не перекрашивает серый сегмент в нейтралов: это исказило бы подтверждённые данные. В интерфейсе поясняется, что «Тип не определён» означает отсутствие однозначной категории, а не потерянный фарм.

## Self-review и границы

Проверен совокупный diff относительно main: изменены представление, локальная навигация/история, проверки формы подготовки и честное отсутствие оценки неизвестного матчапа. Расчёты фарма, экономики, винрейта, подтверждение роли и семантика челленджа сохранены. При просмотре исправлены перекрытие подписей столбцов, мобильные переносы выборок, выравнивание трёх полей и обработка имён, совпадающих с ключами прототипа JavaScript.

- Реальными данными проверена диагностика фарма на **двух сохранённых ответах** и существующих результатах декодирования реплеев. Повторного декодирования `.dem` и просмотра Dota-клиента в этой работе не было.
- Скриншоты и проверки взаимодействий **синтетические**; они не доказывают доступность текущих матчей в API.
- Свежие ответы STRATZ для **9075236042 / 9077889775** здесь недоступны. Состав серого сегмента именно этих матчей и причина отсутствия матча у STRATZ не установлены.
- Координаты не включены в пользовательские выводы; `productReady=false`. Фоновая проверка новых матчей, новые роли, оценка агрессии по урону на линии и новые build-рекомендации не добавлялись.
- PR оставлен для проверки владельцем; автоматическое слияние и закрытие исследовательских issues не выполняются.
