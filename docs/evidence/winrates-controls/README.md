# Доля побед и фоны страниц — проверка 6 ноября 2026

Изменение подготовлено от `main` после PR #76 (`cfebd5f`).

## Поведение

- На `/winrates` — Account ID, период списка матчей и явно объяснённая граница
  истории участников. Переключатель «Представление» удалён.
- Ссылка из разбора с `matchId` по-прежнему открывает конкретный матч. Переход
  «К истории игрока» переносит выбранный известный аккаунт; анонимному участнику
  не подставляется прежний аккаунт. Навигация сбрасывает предыдущие запросы/отчёт.
- «До начала матча» — отдельная граница для каждого матча. «На сегодня» — единая
  граница начала загрузки. Сам выбранный матч исключается в обоих случаях.
  Начало загрузки, начало матча и граница истории подписаны раздельно.
- Форма ограничена 1120 px, контролы выровнены независимо от высоты подсказок.
  На телефоне поля идут друг под другом. Средние, сортировка, экспорт и полнота
  окон 7/30 дней сохраняют прежнюю логику.
- Главная, план перед игрой, история участников и разбор имеют разные фоны.
  Иллюстрации локальные, декоративные, без анимации; панели непрозрачны.

## Повторение

После `npm ci` и `npm run build`, при доступном Playwright/Chromium:

```sh
START_SERVER=1 EVIDENCE_DIR=/tmp/winrates-controls node scripts/verify-winrates.mjs
```

В среде без Playwright в проекте можно указать `PLAYWRIGHT_MODULE_PATH`,
`CHROMIUM_MODULE_PATH` и `CHROMIUM_EXECUTABLE_PATH`. `ASSET_DIR` опционально задаёт
локальный кэш неизменённых иконок Steam CDN. Новые зависимости приложения не добавлены.
